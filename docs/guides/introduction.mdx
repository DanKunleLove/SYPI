title: What is spi AI?
description: A real-time collaborative system architecture workspace powered by AI.
---

spi AI lets you describe a system in plain English and get a visual architecture diagram on a shared canvas — with your whole team — in seconds.

## Who it's for

- **Developers** who want to draft and share architecture decisions before writing code
- **Architects** who need to review and critique system designs collaboratively
- **Technical leads** who want to hand off a structured spec to an AI coding agent (Claude Code, Codex, Lovable, v0)
- **Product managers and founders** who want to explain a system without writing code

## Core concept

Every project in spi AI is a **canvas**. The canvas holds **nodes** (services, databases, caches, queues, etc.) connected by **edges** with labeled data flows.

You build the canvas by:
- Describing your system to the **AI Twin**, which plans and generates it for you
- Dragging nodes from the palette and connecting them manually
- Starting from one of the **built-in templates**

Once your canvas is ready, you can:
- Export it as a **PNG image**, **Markdown spec**, **Mermaid diagram**, or a full **Agent Bundle** for your AI coding agent
- Share it with collaborators who see your cursor in real time
- Run an **AI design review** that surfaces reliability, scalability, and security issues
