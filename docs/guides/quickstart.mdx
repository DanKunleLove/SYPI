---
title: Quickstart
description: Generate your first system architecture in under 2 minutes.
---

## 1. Create a project

After signing in, click **New Project** in the sidebar or on the dashboard. Give it a name and click **Create**.

You'll land on an empty canvas.

## 2. Open the AI Twin

Click the **Generate** button in the top-right toolbar. The AI Twin panel opens on the right.

## 3. Describe your system

Make sure **Generate** mode is selected (the default). Type a description of what you want to build:

```
E-commerce platform with microservices, Redis cache, Kafka event bus, and PostgreSQL
```

Press **Ctrl+Enter** or click the send button.

## 4. Review the plan

The AI Twin drafts a short plan showing the components it will create and the key decisions it made. Read it, then:

- Click **Approve & Generate** to proceed
- Click **Refine** to edit your prompt and re-plan

## 5. Watch it build

Nodes appear on the canvas one by one. Each node has a label, type badge, and description. Edges show the data flows between them.

When placement is complete, the canvas auto-fits so you can see the full diagram.

## 6. Export

Click **Download** (the arrow icon in the toolbar) to open the Spec tab, or press **Ctrl+S** to save.

From the Spec tab you can:
- Copy or download the **Markdown spec**
- Export as a **PNG image** for slides
- Download the **Agent Bundle** (a ZIP your AI coding agent can read)

<Tip>
  The **Agent Bundle** includes a pre-written `CLAUDE.md` that gives Claude Code full context about your system — components, data flows, and an ordered task list to implement it.
</Tip>
