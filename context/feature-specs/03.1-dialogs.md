# Unit 03.1 — Editor Home, Project Dialogs & Sidebar Actions

## Goal

Build the `/editor` home screen with a recent projects grid, add fully-wired project dialogs (Create / Rename / Delete / Duplicate), and upgrade the sidebar with a collapsible projects list, search/filter, and context menus. No API calls or persistence — mock data only.

Inspired by n8n and make.com: the sidebar should feel like a real workflow tool where your projects are always accessible, and the dialogs should be polished with keyboard support and smooth animations.

---

Reuse the existing editor layout. Do not modify the navbar or sidebar structure.

Replace the current `CanvasArea` empty-state content with the editor home view (shown when no project is active):

- Heading: "Create a project or open an existing one"
- Description: "Start a new architecture workspace, or choose a project from the sidebar."
- "New Project" button with `Plus` icon — opens Create Project dialog
- **Recent Projects grid** below — 3-4 mock project cards in a responsive grid:
  - Project name
  - Last edited timestamp (relative: "2 hours ago")
  - Node count badge
  - Subtle hover elevation + border color shift

## Dialogs

All dialogs use shadcn `Dialog` with `rounded-2xl`, backdrop blur, Framer Motion enter/exit animations. All support `Escape` to close and focus trapping.

### Create Project

- Project name input (auto-focused)
- Live slug preview below the input — auto-generated from name via slugify (lowercase, hyphens, no special chars)
- Slug updates as the user types (debounce-free, instant)
- Optional description textarea (2 rows, placeholder: "Brief description of your system...")
- **Template picker**: horizontal scrollable row of 4-5 template cards (Blank, Microservices, Serverless, Event-Driven, API Gateway). Each card has an icon and label. "Blank" is selected by default. Templates are visual-only placeholders for now.
- "Create Project" primary button — adds to mock project list
- Enter submits from the name input

### Rename Project

- Pre-filled project name input (auto-focused, text selected on open)
- Current name shown in the dialog description: "Rename [Current Name]"
- Updated slug preview below input
- Enter submits
- "Rename" primary button

### Delete Project

- Destructive confirmation — no input field
- Description: "This will permanently delete [Project Name] and all its data. This action cannot be undone."
- "Cancel" secondary button + "Delete Project" destructive button (red)
- After delete: show a toast notification with "Undo" action (5 second window)
- Toast uses sonner or custom toast component

### Duplicate Project

- No dialog — instant action from context menu
- Duplicates the project with name "[Original Name] (Copy)"
- Shows a brief success toast: "Project duplicated"

## Sidebar Upgrades

### Projects List Section

Add a "PROJECTS" section between the "New Project" button and the nav items.

**Expanded state (sidebar open):**
- Section header: "PROJECTS" label + project count badge
- **Search input**: small search field with `Search` icon, filters projects by name as you type. Only visible when sidebar is expanded.
- Scrollable project list (max-height with `ScrollArea`):
  - Each item shows: color dot (random per project) + project name (truncated)
  - Active project highlighted with the existing indicator bar style
  - Hover reveals a three-dot `MoreHorizontal` icon on the right
  - Three-dot opens a `DropdownMenu` with: Rename, Duplicate, Delete (with red text + destructive style)
- If no projects match search: "No projects found" empty state

**Collapsed state (sidebar collapsed / icon rail):**
- Projects section is completely hidden — only the nav icon items remain
- This gives maximum canvas space when focused on editing
- The "New Project" button stays visible as a `Plus` icon-only button

### Mobile Sidebar

- Sidebar renders as an overlay drawer on screens < 768px
- Semi-transparent backdrop scrim (click to close)
- Slide-in animation from left (Framer Motion)
- Tapping outside or pressing Escape closes the sidebar

## Implementation

### Mock Data

Create a `lib/mock-projects.ts` file with:
- `Project` type: `{ id, name, slug, description, nodeCount, lastEdited, color, template }`
- 4-5 mock projects with realistic names ("E-Commerce Platform", "Payment Gateway", "Chat System", etc.)
- Color palette for project dots (5-6 distinct colors)

### Hook: `useProjectDialogs`

Create `hooks/use-project-dialogs.ts` — a single hook managing all dialog state:
- `dialogState`: which dialog is open (`create | rename | delete | null`)
- `targetProject`: the project being acted on (for rename/delete)
- `openCreate()`, `openRename(project)`, `openDelete(project)`
- `close()` — resets dialog state

### Hook: `useProjects`

Create `hooks/use-projects.ts` — manages the mock project list:
- `projects`: the current list (initialized from mock data)
- `addProject(data)`: adds a new project
- `renameProject(id, newName)`: renames
- `deleteProject(id)`: removes + returns the deleted project (for undo)
- `duplicateProject(id)`: clones with "(Copy)" suffix
- `searchProjects(query)`: filters by name
- `activeProjectId` / `setActiveProject(id)`: tracks which project is selected

### Wiring

| Trigger | Action |
|---------|--------|
| Editor home "New Project" button | Open Create dialog |
| Sidebar "New Project" button | Open Create dialog |
| Sidebar project item click | Set active project |
| Sidebar three-dot > Rename | Open Rename dialog (pre-filled) |
| Sidebar three-dot > Delete | Open Delete dialog |
| Sidebar three-dot > Duplicate | Instant duplicate + toast |
| Recent project card click | Set active project |
