# P5.2 — Spec Export (Markdown)

## Goal

Export the canvas architecture as a structured Markdown technical specification. Optionally enhanced by AI with descriptions, rationale, and implementation notes. Download as `.md` or copy to clipboard.

## Dependencies

- P2.1 (Canvas Node Types) — need canvas data to export
- P3.1 (AI Engine) — AI enhances spec descriptions (optional)

## Scope

### Build

- **"Export" button** — in workspace navbar, triggers spec generation
- **Preview modal** — rendered Markdown preview before download
- **Spec sections:**
  - System Overview (project name + description)
  - Architecture Diagram (Mermaid syntax)
  - Component Breakdown (one section per node: name, type, description)
  - Data Flow (edge connections described in prose)
  - Technology Recommendations (AI-suggested tech per component)
  - Implementation Notes (AI-generated next steps)
- **AI enhancement toggle** — user can generate basic spec (instant) or AI-enhanced spec (Trigger.dev background job)
- **Download** — save as `{project-name}-spec.md`
- **Copy to clipboard** — one-click copy with toast confirmation
- **Empty canvas guard** — "Add components to your canvas before exporting"

### Do NOT Build

- PDF export
- Version history of specs
- Collaborative spec editing
