# P2.2 — Canvas Interactions

## Goal

Add rich interactions to the canvas: context menus, keyboard shortcuts, manual edge creation, multi-select, copy/paste, and undo/redo. Leverage React Flow's built-in features where possible instead of building from scratch.

## Dependencies

- P2.1 (Canvas Node Types) — need styled nodes to interact with
- 03.8 (Base Canvas) — React Flow + Liveblocks foundation

## Scope

### Build

- **Context menu** — right-click on node: Duplicate, Delete, Change Type (submenu), Edit Label. Right-click on canvas: Paste, Add Node (submenu by type), Select All.
- **Keyboard shortcuts:**

| Shortcut | Action |
|----------|--------|
| `Delete` / `Backspace` | Delete selected nodes/edges |
| `Ctrl+D` | Duplicate selected |
| `Ctrl+A` | Select all |
| `Ctrl+Z` | Undo (Liveblocks history) |
| `Ctrl+Shift+Z` | Redo (Liveblocks history) |
| `Ctrl+C` / `Ctrl+V` | Copy / Paste nodes |
| `Escape` | Deselect all |

- **Manual edge creation** — drag from a node's connection handle to another node's handle to create an edge. React Flow handles this natively — wire up `onConnect` callback.
- **Edge types** — default (smooth step), animated (dashed flow). Edge labels editable on double-click.
- **Multi-select** — shift+click to add to selection, drag-select (selection box) on canvas background
- **Add node manually** — double-click canvas background opens a quick-add popover (search node types, click to place)
- **Snap to grid** — 16px grid (already configured in 03.8), visual grid alignment guides on drag

### Do NOT Build

- Node resize
- Custom edge routing/bending
- Copy/paste across different projects
- Undo/redo beyond Liveblocks history (no custom undo stack)
