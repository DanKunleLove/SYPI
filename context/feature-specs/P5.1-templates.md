# P5.1 — System Templates

## Goal

Pre-built architecture templates users can load onto the canvas as starting points. Templates live as static JSON files, loaded from the sidebar's Templates section. Covers the most common architecture patterns.

## Dependencies

- P2.1 (Canvas Node Types) — need node types for template data
- P2.2 (Canvas Interactions) — users need to manipulate templates after loading

## Scope

### Build

- **Templates section in sidebar** — replaces the empty placeholder. Categorized list of templates with search.
- **Template cards** — name, description, node count, category badge
- **Categories:** Web Apps, Backend, Data, DevOps
- **Load template** — click loads nodes/edges onto canvas
- **Conflict dialog** — if canvas has content: "Replace current canvas?" or "Merge with existing?"
- **Template data** — JSON files in `lib/templates/data/`

### Templates

| Template | Category | Nodes | Description |
|----------|----------|-------|-------------|
| Monolith Web App | Web Apps | 3 | Client, Web Server, Database |
| Microservices Platform | Web Apps | 8 | API Gateway, 3 Services, Message Queue, 2 DBs, Cache |
| Serverless API | Backend | 5 | API Gateway, Lambda Functions, DynamoDB, S3, CloudWatch |
| Event-Driven System | Backend | 6 | Producers, Event Bus, Consumers, Dead Letter Queue, Monitoring |
| Real-time Chat | Web Apps | 5 | Client, WebSocket Server, Redis Pub/Sub, PostgreSQL, CDN |
| CI/CD Pipeline | DevOps | 6 | Git Repo, CI Server, Test Runner, Container Registry, K8s, Monitoring |
| ML Pipeline | Data | 6 | Data Lake, Feature Store, Training, Model Registry, Serving, Monitoring |
| E-commerce Platform | Web Apps | 8 | Storefront, Cart, Payment, Inventory, Shipping, Notifications, DB, Cache |

### Do NOT Build

- User-created templates
- Template marketplace
- AI-generated templates
