# P5.4 — Connection Animations

## Goal

Animated data flow visualization on edges. Small dots or dashes travel along connection lines showing how data moves through the system. Toggle-able globally. Pure CSS/SVG animations for performance.

## Dependencies

- P2.2 (Canvas Interactions) — need edges to animate

## Scope

### Build

- **Animated edges** — dots/dashes travel along edge paths from source to target
- **Animation styles:**
  - Flow (default) — dots moving along path
  - Pulse — edge glows periodically
  - Dashed — marching ants effect
  - Static — no animation
- **Global toggle** — button in canvas controls to enable/disable all animations
- **Per-edge control** — right-click edge context menu to set animation style
- **Direction** — animation flows source -> target
- **Performance** — CSS `stroke-dashoffset` animation (GPU-accelerated), no JavaScript animation loops

### Do NOT Build

- Speed controls (one speed is fine)
- Data volume visualization (thicker = more traffic)
- Sound effects
