# P2.1 — Canvas Node Types

## Goal

Build custom React Flow node components with distinct visual styles for each system component type (service, database, queue, cache, gateway, etc.). The base canvas (03.8) renders default React Flow nodes — this spec replaces them with production-grade, styled nodes.

## Dependencies

- P0 (Audit passes) — canvas basics verified working
- 03.8 (Base Canvas) — React Flow + Liveblocks already integrated

## Scope

### Build

- **Custom node component** — `components/canvas/system-node.tsx` — the main node renderer
- **Node type variants** — each type gets a distinct icon, accent color, and shape treatment:

| Type | Icon | Accent | Shape |
|------|------|--------|-------|
| service | `Server` | indigo-500 | rounded-lg |
| database | `Database` | emerald-500 | rounded-lg with cylinder hint |
| queue | `ListOrdered` | amber-500 | rounded-lg |
| cache | `Zap` | orange-500 | rounded-lg |
| gateway | `Shield` | violet-500 | rounded-lg |
| client | `Monitor` | sky-500 | rounded-lg |
| storage | `HardDrive` | teal-500 | rounded-lg |
| function | `Code` | pink-500 | rounded-lg |
| loadbalancer | `GitBranch` | cyan-500 | rounded-lg |
| cdn | `Globe` | blue-500 | rounded-lg |

- **Node anatomy** — each node displays: icon (top-left), title, optional description (truncated), type badge, connection handles (top, bottom, left, right)
- **Node states** — default, selected (accent border + glow), hovered (subtle elevation), AI-generating (pulsing violet border)
- **Connection handles** — styled dots that appear on hover, positioned at cardinal points
- **Node data type** — extend `types/canvas.ts` CanvasNode with all required fields
- **Register with React Flow** — custom node type map in the canvas component

### Do NOT Build

- Node resize or advanced layout
- Context menu (that's P2.2)
- Drag-to-create (that's P2.2)
- AI-generated node placement (that's P3.2)

## Files to Create/Modify

| File | Action |
|------|--------|
| `components/canvas/system-node.tsx` | Create — custom node component |
| `types/canvas.ts` | Modify — extend CanvasNode type with all fields |
| `components/editor/workspace-canvas.tsx` | Modify — register custom node type |
| `lib/canvas-utils.ts` | Create — node color/icon lookup helpers |

## Acceptance Criteria

- [ ] All 10 node types render with distinct icon and accent color
- [ ] Nodes show title, optional description, and type badge
- [ ] Connection handles appear on hover
- [ ] Selected nodes show accent border + subtle glow
- [ ] Hovered nodes show elevation change
- [ ] Nodes use CSS design tokens (no hardcoded colors)
- [ ] Nodes sync correctly through Liveblocks
- [ ] `npm run build` passes clean
