# P3.2 — Prompt to Canvas

## Goal

Wire the prompt bar and AI sidebar to the AI engine. User types a system description, AI generates architecture on the canvas. This is the core product feature.

## Dependencies

- P3.1 (AI Engine) — need both Vercel AI SDK and Trigger.dev pipelines
- P2.1 (Canvas Node Types) — need node types for rendering
- P2.2 (Canvas Interactions) — need canvas to accept programmatic node/edge insertion

## Scope

### Build

**Prompt bar (bottom of canvas):**
- **Activate prompt bar** — click the existing prompt bar shell (built in 02) to enable it
- **Textarea input** — expandable, supports multi-line, submit with Enter (Shift+Enter for newline)
- **Example prompts** — 4-5 clickable suggestions for first-time users:
  - "E-commerce platform with microservices"
  - "Real-time chat application"
  - "CI/CD pipeline with Kubernetes"
  - "Event-driven data processing pipeline"
  - "SaaS application with multi-tenancy"
- **Mode indicator** — "Generate" when canvas is empty, "Refine" when canvas has nodes
- **Submit** — sends prompt to Trigger.dev generate task (full generation) or Vercel AI SDK (quick refinement)

**Generation flow:**
- **Progress indicator** — pulsing AI accent glow on prompt bar + status text ("Generating architecture...", "Placing nodes...", "Drawing connections...")
- **Node placement** — generated nodes appear on canvas with auto-layout (simple grid/hierarchical arrangement)
- **Edge creation** — connections drawn automatically per AI output
- **Completion** — progress indicator clears, canvas fits to view, toast confirms "Architecture generated"

**AI sidebar chat:**
- **Wire `useChat`** — connect the AI sidebar Chat tab to `POST /api/ai/chat`
- **Canvas-aware chat** — AI knows the current canvas state and can answer questions about it
- **Tool execution** — when AI calls `addNode`/`removeNode` tools, changes appear on canvas in real-time
- **Chat history** — persisted per project in the AI sidebar

**Error handling:**
- **Generation failure** — toast with "Generation failed. Try again." + retry button in prompt bar
- **Partial failure** — if some nodes placed before failure, keep what's there, show error for the rest
- **Rate limiting** — disable prompt bar for 3s after submission to prevent spam

### Do NOT Build

- Iterative refinement with diff operations (that's P4.2)
- Smart suggestions (that's P4.3)
- Prompt history panel (defer — chat history in sidebar is sufficient)

- [ ] Generated nodes appear on canvas with correct types and connections

- [ ] Canvas fits to view after generation completes
- [ ] AI sidebar chat responds with streaming text
- [ ] AI sidebar chat knows the current canvas state
- [ ] AI tool calls (addNode, etc.) modify the canvas in real-time

- [ ] Prompt bar shows "Generate" / "Refine" mode correctly
