# P4.3 — Smart Suggestions

## Goal

AI proactively suggests improvements as the user builds. A hybrid engine: fast rule-based pattern checks run instantly in JavaScript, deeper AI analysis runs via Vercel AI SDK after a debounce. Suggestions appear in the AI sidebar's Suggestions tab and as subtle chips near affected nodes.

## Dependencies

- P3.1 (AI Engine) — need Vercel AI SDK for streaming suggestions
- P2.1 (Canvas Node Types) — need canvas state to analyze
- P4.1 (AI Critique) — shares analysis patterns

## Scope

### Build

**Rule-based suggestions (instant, no API call):**

| Pattern | Suggestion |
|---------|------------|
| Database with no cache | "Add a cache (e.g., Redis) between {service} and {database}" |
| Service with no load balancer | "Add a load balancer in front of {service}" |
| Client connects directly to database | "Add an API layer between {client} and {database}" |
| No monitoring/logging node | "Consider adding a monitoring service (e.g., Prometheus, Datadog)" |
| Single point of failure (1 instance of critical service) | "Add redundancy to {service}" |
| 3+ services with no message queue | "Consider adding a message queue for async communication" |

**AI-powered suggestions (debounced, streaming):**
- Deeper architectural analysis beyond simple pattern matching
- Technology-specific recommendations (e.g., "Use PostgreSQL for this relational data" vs "Use MongoDB for this document store")

**UI:**
- **Suggestion chips** — small pills floating near relevant nodes on canvas (non-blocking, dismissible)
- **Suggestions tab** — in AI sidebar, full list with "Apply" and "Dismiss" buttons
- **Apply** — clicking "Apply" triggers a refinement that adds the suggested component
- **Debounce** — suggestions refresh 3 seconds after last canvas change
- **Max suggestions** — show at most 5 active suggestions (avoid clutter)

### Do NOT Build

- Custom suggestion rules
- Suggestion history or analytics
- Team-shared suggestion preferences
