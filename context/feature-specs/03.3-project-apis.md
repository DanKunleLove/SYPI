# Unit 03.3 — Project API Routes

The database schema is ready. Build the backend project API routes only.

## Routes

Create REST endpoints for:

- `GET /api/projects` — list current user's projects
- `POST /api/projects` — create project
- `PATCH /api/projects/[projectId]` — rename project
- `DELETE /api/projects/[projectId]` — delete project

## Response Shapes

### GET /api/projects

```json
{ "projects": [{ "id", "name", "description", "status", "canvasJsonPath", "createdAt", "updatedAt" }] }
```

Sorted by `updatedAt` descending. Return all (no pagination for MVP).

### POST /api/projects

Request body: `{ "name"?: string, "description"?: string }`

```json
{ "project": { "id", "ownerId", "name", "description", "status", "canvasJsonPath", "createdAt", "updatedAt" } }
```

### PATCH /api/projects/[projectId]

Request body: `{ "name": string }`

```json
{ "project": { "id", "ownerId", "name", "description", "status", "canvasJsonPath", "createdAt", "updatedAt" } }
```

### DELETE /api/projects/[projectId]

```json
{ "success": true }
```

### Error responses

```json
{ "error": "Human-readable message" }
```

Status codes: `401` (unauthenticated), `403` (not owner), `404` (project not found), `400` (validation failure).

## Rules

Use the authenticated Clerk user ID as `ownerId`.

When creating:

- Default missing project name to `"Untitled Project"`
- Use the schema's existing ID strategy (cuid), do not add sequential IDs

Security:

- Require authentication for all endpoints
- User should only access their own projects
- Unauthenticated requests return `401`
- Only the project owner can rename or delete
- Non-owner mutations return `403`

Keep this backend-only. Do not wire the UI yet.

## Check When Done

- Routes return correct JSON matching the response shapes above
- Unauthenticated requests return 401
- Mutations fail with 403 when run by non-owner
- Project deletion cascades to collaborators (handled by Prisma `onDelete: Cascade`)
- Prisma client is correctly wired and queries run
- `npm run build` passes cleanly
