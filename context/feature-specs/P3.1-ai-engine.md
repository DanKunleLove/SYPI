# P3.1 — AI Engine

## Goal

Set up the dual AI infrastructure: **Vercel AI SDK** for streaming interactive responses (chat, quick refinements) and **Trigger.dev** for heavy background jobs (full architecture generation, deep critique, spec export). Both use Claude (Anthropic) as the LLM provider.

## Dependencies

- P1.1 (Database Hardening) — need AIGeneration model
- P2.1 (Canvas Node Types) — need canvas types for structured output

## Architecture

```
User Action
    |
    v
[Interactive / Fast]              [Heavy / Background]
    |                                  |
Vercel AI SDK                     Trigger.dev
(streaming, <10s)                 (background, 10-60s)
    |                                  |
    v                                  v
- AI sidebar chat              - Full architecture generation
- Quick suggestions            - Deep design critique
- Inline refinements           - Spec generation with AI enhancement
- Edge label suggestions       - Batch canvas operations
    |                                  |
    +------------- Claude API ---------+
    |                                  |
    v                                  v
Stream to UI                   Write to Liveblocks + DB
```

## Scope

### Build

**Vercel AI SDK layer:**
- **AI route handler** — `app/api/ai/chat/route.ts` using `streamText` from Vercel AI SDK
- **System prompt** — architecture-aware prompt that understands canvas context
- **Tool definitions** — tools the AI can call: `addNode`, `removeNode`, `addEdge`, `updateNode` (these write to Liveblocks)
- **Chat hook** — `useChat` from Vercel AI SDK wired to the AI sidebar

**Trigger.dev layer:**
- **Trigger.dev config** — `trigger.config.ts` project setup
- **Generate architecture task** — takes a prompt + optional existing canvas context, returns full node/edge set
- **Job status tracking** — AIGeneration row tracks pending/running/completed/failed
- **Result handler** — completed jobs write nodes/edges to Liveblocks storage
- **Retry logic** — up to 2 retries on failure, with error logged to AIGeneration

**Shared:**
- **AI service** — `lib/ai/index.ts` — shared Claude client config
- **System prompts** — `lib/ai/prompts.ts` — prompts for generation, chat, critique
- **Output schemas** — `lib/ai/schemas.ts` — Zod schemas validating LLM output (node arrays, edge arrays, critique results)
- **Canvas serializer** — `lib/ai/canvas-context.ts` — converts current Liveblocks canvas state into a compact text representation for AI context

## Acceptance Criteria

- [ ] `POST /api/ai/chat` streams a response using Vercel AI SDK
- [ ] AI understands canvas context (knows what nodes exist)
- [ ] AI tools (`addNode`, `removeNode`, etc.) are defined and callable
- [ ] Trigger.dev dev server runs alongside Next.js (`npx trigger.dev dev`)
- [ ] `POST /api/ai/generate` triggers a background job, returns jobId
- [ ] `GET /api/ai/status/[jobId]` returns current status
- [ ] Completed generation job writes valid nodes/edges to Liveblocks
- [ ] AIGeneration row created in DB with prompt, status, result
- [ ] Invalid LLM output caught by Zod, logged, and retried
- [ ] Failed jobs after retries set status to "failed" with error message
- [ ] `npm run build` passes clean
