# P1.2 — Dashboard

## Goal

Build the main dashboard at `/dashboard` — the first screen after sign-in. Project grid with cards, "Shared with me" section, and quick actions. Inspired by n8n's workspace layout: clean grid, timestamps, visual hierarchy.

## Dependencies

- P1.1 (Database Hardening) — need Collaborator model for shared projects
- Auth (Clerk) — already configured

## Scope

### Build

- **Dashboard page** at `/dashboard` — server component, fetches projects
- **Dashboard navbar** — logo, search bar (filter projects client-side), user menu (Clerk UserButton)
- **Tab navigation** — "My Projects" | "Shared with Me"
- **Project cards** — name, description preview, last edited timestamp (relative: "2 hours ago"), node count badge, owner avatar (for shared projects)
- **Card actions** — three-dot menu: Rename, Duplicate, Delete, Share
- **Create project** — prominent "New Project" button, opens dialog with name input + optional template picker
- **Empty states** — distinct empty states for "no projects yet" and "no shared projects"
- **Loading skeleton** — card-shaped skeletons while data fetches
- **Redirect logic** — `/` redirects signed-in users to `/dashboard`, signed-out users see landing page

### UI Patterns (from competitor research)

| Element | Pattern | Reference |
|---------|---------|-----------|
| Project grid | 3-column responsive grid (1 on mobile, 2 on tablet, 3 on desktop) | n8n, Figma |
| Card hover | Subtle border glow + slight elevation | Notion |
| Timestamps | Relative time ("3 days ago") with tooltip showing absolute date | GitHub |
| Empty state | Centered illustration + heading + CTA button | Linear, Notion |
| Search | Inline filter (no server round-trip), matches name/description | n8n |

### Do NOT Build

- Pagination (premature — handle when users have 50+ projects)
- Project thumbnails/previews (requires canvas screenshot — defer to P5)
- Folders or project organization
- Dashboard analytics or usage stats
