# P1.1 — Database Hardening

## Goal

Solidify the Prisma schema and database layer for production. The current schema (from 03.2) works but needs hardening: Clerk webhook sync, proper indexes, and the Collaborator model needs to be a first-class relation.

## Dependencies

- P0 (Bug Fixes & Audit) — foundation must be verified first
- Clerk configured (already done)
- Neon PostgreSQL configured (already done)

## Scope

### Build

- **Clerk webhook handler** — `POST /api/webhooks/clerk` syncs user creation, updates, and deletion to the User table. Verify with Svix signature validation.
- **User model cleanup** — ensure User has: id, clerkId (unique), email (unique), name, imageUrl, createdAt, updatedAt
- **Collaborator as a relation** — currently collaborators are stored as a JSON array on Project. Migrate to a proper Collaborator join table with role enum (OWNER, EDITOR, VIEWER).
- **Database indexes** — add indexes on frequently queried fields: Project.userId, Collaborator.userId, Collaborator.projectId
- **Cascade deletes** — deleting a User cascades to their owned Projects. Deleting a Project cascades to Collaborators and AIGeneration records.
- **AIGeneration model** — add table to track AI prompts, status, and results per project (needed by P3)
- **Seed script** — `prisma/seed.ts` for local development with sample users and projects

### Do NOT Build

- Canvas state in DB (lives in Liveblocks)
- API routes for new models (that's P1.2)
- Migration to a different DB provider

## Schema Changes

```prisma
enum Role {
  OWNER
  EDITOR
  VIEWER
}

model User {
  id             String         @id @default(cuid())
  clerkId        String         @unique
  email          String         @unique
  name           String?
  imageUrl       String?
  ownedProjects  Project[]
  collaborations Collaborator[]
  createdAt      DateTime       @default(now())
  updatedAt      DateTime       @updatedAt
}

model Project {
  id            String         @id @default(cuid())
  name          String         @default("Untitled Project")
  description   String?
  userId        String
  user          User           @relation(fields: [userId], references: [id], onDelete: Cascade)
  collaborators Collaborator[]
  generations   AIGeneration[]
  createdAt     DateTime       @default(now())
  updatedAt     DateTime       @updatedAt

  @@index([userId])
}

model Collaborator {
  id        String   @id @default(cuid())
  projectId String
  project   Project  @relation(fields: [projectId], references: [id], onDelete: Cascade)
  userId    String?
  user      User?    @relation(fields: [userId], references: [id], onDelete: Cascade)
  email     String
  role      Role     @default(EDITOR)
  createdAt DateTime @default(now())

  @@unique([projectId, email])
  @@index([userId])
  @@index([projectId])
}

model AIGeneration {
  id        String   @id @default(cuid())
  projectId String
  project   Project  @relation(fields: [projectId], references: [id], onDelete: Cascade)
  prompt    String
  status    String   @default("pending")
  result    Json?
  error     String?
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([projectId])
}
```
