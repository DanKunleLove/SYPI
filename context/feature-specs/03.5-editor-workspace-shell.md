Build the `/editor/[roomId]` workspace shell with server-side access checks. No canvas logic yet.

## Access

`/editor/[roomId]` must be a server component.

Before rendering:

- Clerk middleware already protects `/editor(.*)` — unauthenticated users redirect to sign-in automatically
- Users without project access see `AccessDenied`
- Non-existent projects also show `AccessDenied`

Create `components/editor/access-denied.tsx` with:

- centered layout with dark background
- lock icon (Shield or Lock from lucide)
- short message explaining the issue
- link back to `/editor`

## Access Helpers

Create `lib/project-access.ts` with helpers for:

- getting current Clerk identity: `userId` + primary email
- checking project access by owner (collaborator support added later)
- fetching project by ID with access check in one call
