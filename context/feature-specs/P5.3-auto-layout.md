# P5.3 — Auto Layout

## Goal

One-click automatic arrangement of nodes on the canvas using Dagre (directed graph layout algorithm). Messy diagrams become clean, readable layouts with smooth Framer Motion transitions.

## Dependencies

- P2.1 (Canvas Node Types) — need nodes to arrange
- P2.2 (Canvas Interactions) — nodes must support programmatic repositioning

## Scope

### Build

- **"Auto-layout" button** — in canvas controls (bottom-left, near zoom)
- **Layout algorithm** — Dagre for directed graph layout
- **Layout directions:**
  - Hierarchical top-to-bottom (default) — clients top, databases bottom
  - Left-to-right — data flows left to right
- **Animated transitions** — nodes smoothly animate to new positions via Framer Motion (300ms, easeOut)
- **Spacing** — sensible defaults (horizontal: 80px, vertical: 60px)
- **Undo** — layout change is one Liveblocks history entry (Ctrl+Z reverts)

### Do NOT Build

- Circular layout (rare use case, adds complexity)
- Manual spacing controls (defaults are sufficient)
- Preserve-manual-position toggle (over-engineering)

## Packages

```bash
npm install @dagrejs/dagre
```

- [ ] "Auto-layout" button arranges all nodes cleanly
- [ ] Nodes animate smoothly to new positions (not teleport)
- [ ] Top-to-bottom and left-to-right directions work
- [ ] Layout respects edge connections (connected nodes positioned logically)
- [ ] Ctrl+Z reverts the layout as one undo step
